# CVM++

A stack-based virtual machine and mini compiler implemented in C++.

This project demonstrates the complete compilation pipeline of a simple custom scripting language. The source code is tokenized by a lexer, parsed into an Abstract Syntax Tree (AST), compiled into bytecode instructions, and finally executed by a stack-based virtual machine.

---

## Features

- Custom Lexer / Tokenizer
- Recursive Descent Parser
- Abstract Syntax Tree (AST) Construction
- Bytecode Generation
- Stack-Based Virtual Machine
- Variable Assignment
- Arithmetic Expressions
- Print Statements

---

## How It Works

### 1. Lexical Analysis

The lexer reads the source code and converts it into a stream of tokens.

Example:

```txt
let x = 10
```

becomes

```txt
LET IDENTIFIER(x) ASSIGN NUMBER(10)
```

### 2. Parsing

The parser processes the tokens and builds an Abstract Syntax Tree (AST) representing the program structure.

### 3. Bytecode Generation

The compiler traverses the AST and converts it into bytecode instructions.

### 4. Virtual Machine Execution

The virtual machine executes the generated bytecode using a stack-based execution model.
